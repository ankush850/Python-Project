# Data Wrangling & Exploratory Data Analysis (EDA) Projects

This directory contains in-depth data wrangling, data quality assessment, and exploratory data analysis projects across diverse real-world domains.

---

## 📁 Projects in this Directory

### 1. [WeRateDogs Twitter Data Wrangling (`HarshDeepKalita-Data-Analyze-and-Wrangle-Project`)](file:///d:/Data-Analyst-Mini-Projects-main/Data%20Wrangling%20and%20EDA/HarshDeepKalita-Data-Analyze-and-Wrangle-Project/README.md)
- **Focus**: Multi-source data gathering (CSV, TSV via HTTP requests, JSON via Twitter archive), assessing quality & tidiness issues, programmatically cleaning datasets, and generating visual insights on dog ratings and retweets.
- **Tech Stack**: Pandas, NumPy, Requests, Seaborn, Matplotlib, Jupyter.

### 2. [TMDb Movies Dataset Investigation (`Harsh_Deep_Kalita_TMDb_DataSet`)](file:///d:/Data-Analyst-Mini-Projects-main/Data%20Wrangling%20and%20EDA/Harsh_Deep_Kalita_TMDb_DataSet/README.md)
- **Focus**: Exploratory data analysis on 10,000+ movies from The Movie Database (TMDb) investigating profitability, budget trends, popular genres, runtime correlations, and director success.
- **Tech Stack**: Pandas, NumPy, Seaborn, Matplotlib, Jupyter.

### 3. [Spotify Favorite Artists Music EDA (`Spotify-EDA`)](file:///d:/Data-Analyst-Mini-Projects-main/Data%20Wrangling%20and%20EDA/Spotify-EDA/README.md)
- **Focus**: Audio feature analysis (danceability, valence, energy, tempo, loudness, liveness) across 17 top musical artists using the Spotify Web API (`spotipy`) and PyWaffle waffle charts.
- **Tech Stack**: Pandas, NumPy, Spotipy, PyWaffle, Seaborn, Matplotlib, Jupyter.
