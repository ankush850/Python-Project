# Classic Retro Snake Game (Python Turtle Graphics)

## 📌 Project Overview
A recreation of the classic arcade **Snake Game** built using Python's built-in **Turtle Graphics** module. The project demonstrates game loops, event handling, collision detection, and Object-Oriented game entity design.

---

## 🎮 How to Play & Controls
- **Up Arrow / W**: Move Up
- **Down Arrow / S**: Move Down
- **Left Arrow / A**: Move Left
- **Right Arrow / D**: Move Right
- **Goal**: Navigate the snake to eat the food dots, grow longer, and avoid running into boundaries or biting your own tail.

---

## 🏗️ Project Structure
- **`snake.py`**: Encapsulates the snake segments, directional movements, key bindings, and growth logic.
- **`food.py`**: Manages randomized food placement across the game canvas.
- **`main.py`**: Configures screen dimensions, runs the main game loop, and handles collision detection.

---

## 📦 Requirements & Installation
This project runs entirely on the **Python Standard Library** (`turtle`, `time`, `random`) and requires no additional package installations.

---

## 🚀 How to Run
Run the game launcher:

```bash
python main.py
```
