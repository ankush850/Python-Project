# Desktop Calculator (Tkinter & PySide6)

## 📌 Project Overview
A dual-implementation graphical desktop calculator project featuring two distinct GUI frameworks in Python:
1. **Tkinter Implementation (`calculator.py`)**: Lightweight native Python standard GUI.
2. **PySide6 / Qt Implementation (`calculator (2).py`)**: Modern Qt-based desktop calculator with keyboard shortcuts and responsive grid layout.

---

## ✨ Features
- Basic arithmetic operations: Addition ($+$), Subtraction ($-$), Multiplication ($*$), Division ($/$).
- Clear screen (`Clear`) and instant evaluation (`=`).
- Keyboard input support and shortcut bindings (in the Qt version).

---

## 📦 Requirements & Installation
Tkinter is bundled with standard Python installations. To run the PySide6 version, install:

```bash
pip install -r requirements.txt
```

### Dependencies
- `PySide6` - Python Qt framework (for `calculator (2).py`)
- Python standard library: `tkinter`, `sys`

---

## 🚀 How to Run

### Run the Tkinter Calculator:
```bash
python calculator.py
```

### Run the PySide6 (Qt) Calculator:
```bash
python "calculator (2).py"
```
