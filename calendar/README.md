# Desktop Calendar Application (PySide6)

## 📌 Project Overview
An interactive graphical calendar desktop application built with **PySide6 (Qt for Python)**. It dynamically displays monthly grids with localized weekdays, highlighted current dates, and smooth navigation between months and years.

---

## ✨ Features
- Monthly calendar grid with automatic day-of-week alignment.
- **Previous (`< Previous`)** and **Next (`Next >`)** buttons to navigate seamlessly across months and years.
- Dynamic localized date parsing using `QDate` and `QLocale`.
- Clean, customizable Qt grid layout.

---

## 📦 Requirements & Installation
Install the required PySide6 framework:

```bash
pip install -r requirements.txt
```

### Dependencies
- `PySide6` - Python bindings for the Qt toolkit
- Python standard library: `sys`

---

## 🚀 How to Run
Run the calendar script:

```bash
python calendar.py
```
